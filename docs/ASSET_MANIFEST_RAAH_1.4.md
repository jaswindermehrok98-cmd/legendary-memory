# Asset Manifest — RAAH Personal Edition 1.4

This release adds rendering and material work using procedural assets. No new external art asset has been downloaded.

| Asset / system | Source | Licence / status |
|---|---|---|
| World geometry, buildings, characters, vehicles and props | Procedural meshes defined in the HTML source | Project-authored code; no separate asset file |
| Surface textures | Runtime canvas-generated textures | Generated at runtime; no external source |
| Sky dome texture | Runtime canvas-generated gradient/cloud texture | Generated at runtime; no external source |
| Engine | PlayCanvas Engine 2.23.2 from jsDelivr CDN | Third-party open-source engine; check its repository for licence terms |
| Fonts | System font stack | User system fonts; no embedded font assets |

No claims are made that current characters are professional rigged models or that the environment is photorealistic.
